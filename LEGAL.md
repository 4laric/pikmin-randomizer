## Distribution rule

Neither the repository, nor releases, nor CI artifacts contain, and must never contain:

- ISO/GCM/RVZ/WIA/GCZ images or other disc dumps;
- extracted `dataDir` game files or anything derived from them;
- packages that combine the port with proprietary game data.

The launcher reads a disc image or assets folder the user provides locally, never downloads one, never bundles one, and does not circumvent any access protection. Each user is responsible for obtaining and using their copy of Pikmin lawfully.
