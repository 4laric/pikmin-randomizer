# Valley of Repose entrance preparation (#114/#132)

`py -3.12 -m experimental.pikmin2_surface_pocket --iso <local GPVE01 revision 0 ISO> --output <new private directory>` extracts the actual `tutorial` surface and generator files. No assets are committed or redistributed. The output must be new; live saves and bundles are never read or replaced.

The source `user/Abe/map/tutorial/defaultgen.txt` places Emergence (`tutorial_1.txt`, cave ID `t_01`) at **(-190, 80, 1160)**, yaw **-45 degrees**, with zero generator offset. It places the ship at (-137.643, 0, 3033.014) and regular Onion actors nearby. Those are actor anchors, not proof that all are active in a particular story state. Generator manager header startPos is zero; do not use it as a validated captain landing spawn. Version 0.1–0.3 disc generator headers follow `native/pikmin2-research/src/plugProjectKandoU/gameGenerator.cpp::Generator::read`; CP932 preserves Japanese source labels.

The imported whole-surface static MOD has 14,161 vertices, 21,748 triangles, 31 shapes, and 37 textures. Source bounds are [-3920.25,-80,-3610.25] to [3050.75,1500,6583]. This is real terrain, with no cropped or fabricated collision floor. Material approximations and omitted `texanm_1.btk` remain visible limitations. The source includes three water boxes. The existing dry-room decoder rejects material 3; this importer records that blocker instead of coercing it to a dry material or producing an apparently walkable map.

`surface-pocket.json` retains source hashes, every parsed generator inventory, source entrance/return reference, landing actors, water data, and explicit blockers. `surface-render.mod` is suitable for the next isolated rendering integration; it is not currently a playable scene. Raw grid/mapcode/routes remain available for the collision owner's surface audit.

The minimum native integration contract is: load this terrain with audited collision and water; place a captain and active party at a validated dry position; display the source entrance and emit a guarded surface-entry handoff containing actual position/day/time/party/health/receipts; after cave return, consume the authoritative ledger and restore party near a collision-checked entrance offset. Existing SurfaceLedger fields can represent that snapshot. The source cave origin is an anchor reference, not an assertion of the vanilla return formation. `singleGS_MainGame.cpp::GameState::onMovieStart` saves the main-map situation and passes the current cave position to `prepareHoleIn`; full actor/storage/two-captain restoration and story scheduling remain unimplemented.

Native test reports now capture the executable path and SHA256 before execution. Historical `native-ledger-01` remains hash-unknown; it is not relabeled using a subsequently replaced fixture binary.
