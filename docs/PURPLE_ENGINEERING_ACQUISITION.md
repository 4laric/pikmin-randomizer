# Purple engineering acquisition profile

The private SDL save/resume fixture accepts `--engineering-acquire-90` together with `--development-launch --mode sdl_save_resume --profile ordinary-off`. This explicitly allows up to 90 monotonic wall seconds for verified natural acquisition and a separate 60 seconds for ordinary SAVE. Fresh resume stays at 60 seconds. The default acquisition limit stays at 60 seconds.

The native phase transition is one-way and requires genuine acquisition. The profile changes no game clock, movie, actor, collision margin, population accounting, probe or pulse count. It does not claim retail timing, unseen animation safety, gameplay acceptance or SAVE success. Native and wrapper evidence must report the same 90/60/150 limits.

The measured basis is the failed Probe21 run: the head first became naturally pluckable at 52.3975 wall seconds; nine verified movement pulses advanced 26.02 units in 4.928 seconds. The 65.538-unit route needs roughly 12.41 seconds at that cadence before the pluck animation. The historical 60-second failure remains preserved.
