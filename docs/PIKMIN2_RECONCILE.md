## Findings

- The hard-lane seam really is absent (`pc_p2_hardlanes.cpp` and the
  `pc_p2_bigtreasure_*` attack/fsm/host files). This is the largest integration
  gap and the #244/#245/#246 modules exist only on the worker branches.
- Sokkuri/Armor are already in the base, so the species batch is only the
  Mar/Tadpole (and remaining ground-six) deltas, not a re-integration.
- `6b71b14` is not an ancestor but its content is byte-identical in the base:
  ancestry alone understates what is integrated. Each batch must compare trees,
  not just commits.
- Merge tips undercount changes. The cannon `656c556` tip shows one doc; the
  actual seams live on the `opencode/p2-*` branches and native `104d6dfa`. Lane 01
  must pin the specific module commits, not the merge tip.
- Native-only work (`fb6389ce`) cannot be reconciled from the root repo; it needs
  the native worktree.
