# White native checkpoint fixture (#1111)

This bounded preview fixture acquires one White from an Ivory bud with real SDL controller input and player plucking, walks the captain to the existing Research Pod and calls the production cave checkpoint without its confirmation dialog. A fresh consumer accepts only the hash-verified successful producer packet, then uses native ENTRY_2 restoration and verifies 19 Red + 1 White, leaf maturity, no sprouts and 20 bodies.

Every run regenerates the current 20-body arena, asserts a centered 960×540 window, checks the canonical captain guard before readiness waits and runs under the canonical 60-second supervisor. A negative guard run must exit 86 without a success marker. Producer raw exit 42 is preserved separately from the supervisor's zero-exit verdict.

Startup skips movies and suppresses tutorial flags. The checkpoint captures global living actors: full-squad arrival, the confirmation interface, Ivory spent-budget continuity, ship storage, day-save, Archipelago and full White campaign behavior remain untested. Consumer species/maturity restoration is an existing production operation, not evidence of another natural White acquisition.

Use `scripts/run_p2_white_checkpoint.py --mode producer` with the required workspace/executable/local asset paths. Then use `--mode consumer --producer <accepted run directory>` with the same paths. Tampered or failed producer packets are refused before staging or launching. Use `--mode negative` for captain guard refusal.
