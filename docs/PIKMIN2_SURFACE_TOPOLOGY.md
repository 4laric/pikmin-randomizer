# Valley nonmanifold topology audit (#114)

`experimental.pikmin2_surface_topology` classifies the source geometry without changing a vertex, triangle, winding or mapcode. Run it against the surface-physics output; it requires the water sidecar and hashes both source files. It emits an audit only, never an automatically repaired native map.

The actual Valley data contains 18 overfull edges, with **zero safe coplanar reciprocal pairs** under the current native smooth-floor conditions. Most are wall/slope/top junctions; five edges touch two coincident face groups. Faces 673/4914 and 727/4915 have the same winding but mapcodes 103/65: steep slip2 versus slip0 (and different material). They are not equivalent physics duplicates and cannot simply be removed. No opposite-winding duplicate pair was found in the source.

`native/pikmin2-research/include/Sys/Triangle.h` stores vertex indices, face/edge planes and mapcode, with no adjacency index. `src/sysCommonU/geometry.cpp` performs triangle/edge collision independently. The P1 representation in `native/include/Collision.h` stores one signed-short neighbor per edge. This is more than a loader restriction: `creatureMove.cpp` consults it before `jumpCallback` on loss of ground, `creature.cpp` follows it for shadows, and `mapMgr.cpp::p2SmoothStaticFloorEdge` requires reciprocal same-plane peers to suppress internal edge collision. Assigning -1 to every overfull edge therefore cannot be claimed behavior-neutral; arbitrarily choosing one peer also loses source possibilities.

The audit records every incident source triangle, normal, mapcode, angle, winding relationship and duplicate relationship. Even a hypothetical uniquely smooth pair does not approve conversion while another incident face remains unrepresented. Tests cover manifold geometry, wall junctions, same/reversed winding duplicates, changed slip codes, degenerate references, and unchanged source arrays.

Next full-surface gate: implement and validate a native multi-incident ground-transition policy that retains all source planes and mapcodes, or demonstrate an equivalent selected adjacency using native contact/ground-transition tests. An explicitly bounded entrance-only subset is a separate useful alternative, but must retain original geometry, declare its travel boundary, preserve water, and not claim to repair or include the entire Valley.
