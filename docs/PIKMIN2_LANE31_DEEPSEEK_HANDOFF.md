## Concrete source ID and missing gate addressed

- **Source enemy ID: 99 `BlackMan`** (Waterwraith), with its **98 `Tyre`** helper
  roller. Owns `pc_port/pc_p2_waterwraith*` modules only.
- Missing slice closed: **the lifetime tail past the registered actor/roller
  gates** — once the roller child is destroyed, the exposed dismounted body must
  stay damageable, reach zero, execute the source Dead key sequence (KEYEVENT_5
  releases the treasure, KEYEVENT_END kills), drop a real on-field corpse, tear
  the seam down, and re-enter cleanly.

## What was wrong and what changed

`p2_waterwraith_actor_apply_damage` gated the exposed body on
`P2WaterwraithRig::damageable()`. After the Tyre child finished its `tyre_getoff`
death and was removed, the rig reports `!alive`, so `damageable()` returned
false and **body death was unreachable** — the natural combat chain stalled at
"roller removed". Fix: route body damage on the *dismount* flag
(`ownerInvulnerableSet()`, the source EB_Invulnerable that persists past
`finishDead`) instead of the roller's own gate, so the exposed body remains
vulnerable until the wraith itself dies. The register seam now consumes the
Dead key sequence end-to-end: KEYEVENT_5 spawns a labelled number-pellet corpse
stand-in at the wraith position (the same P1-host adaptation the Kogane lane
documents; the host has no P2 treasure item), KEYEVENT_END tears the seam down
(`finished` stops further tick/draw), and reset + re-setup reproduces a fresh
actor with restored health.

### Why BLOCKED (exact file:line)

The corpse stand-in is `pelletMgr->newNumberPellet(PELCOLOR_Blue, NUMPEL_OnePellet)`
(`pc_port/pc_p2_waterwraith_register.cpp` `spawnWraithCorpse`). That path is
`PelletMgr::newPellet(id, nullptr)` → view-less `initPellet(obj, config)`
(`src/plugPikiKando/pelletMgr.cpp:1555`, `:1581-1594`), leaving `mPelletView == nullptr`
(`registered=0` in the run). The lane-06 Pod receipt path
(`pc_p2_preview_deliver` -> `pc_p2_waterwraith_receipt`) and every dead-Teki corpse
receipt key on `pellet->mPelletView` (`pc_p2_preview.cpp:326-336`), so a view-less
stand-in is invisible and cannot be picked up/transported. A view-backed corpse
requires `PelletView::becomePellet` (`pelletMgr.cpp:166`) with a live `PelletView*`,
which only an engine Teki corpse provides (cf. Mamuta `TEKI_Miurin`); this virtual,
non-Teki Waterwraith actor has none.
