# Uji lethal-interaction diagnostic

The ten-actor fixture's initial shortcuts did not establish a production death bug. Both native P1 proxy Waiting states explicitly enable invincibility, set manual animation speed to0, and omit the dead-check action (`TAIkabekuiA.cpp:230,267` and `TAIkabekuiB.cpp:257,303`). `BTeki::interactDefault` rejects ordinary attacks while invincible; otherwise it accumulates stored damage (`tekibteki.cpp:1776`). Vulnerable Moving states apply `TAIAdamage` and then `TAIAdeadCheck`.

Normal emergence uses `TAIAappearKabekui`, derived from `TAIAsetMotionSpeed`, restoring configured motion speed and visible state. Directly assigning health0 bypasses attack eligibility and damage processing. Directly jumping from Waiting into Dying bypasses emergence too: `TAIAdying::start` starts a motion but does not reset manual speed, while `TAIAmotion::start` only switches motion. The retained zero speed can therefore prevent the final animation event needed for corpse conversion. This is a concrete invalid-fixture setup, not evidence of an offscreen regression.

The new private diagnostic `experimental.pikmin2_uji_legal_diagnostic.py` targets one source-registered male and female without relocating them. It asserts that buried lethal InteractAttack calls are rejected without damage, drives the captain along the source-connected route to trigger normal emergence, then submits a lethal InteractAttack after each target becomes vulnerable. It observes native corpse creation without health/state/position writes. The attack call is injected developer input, not physical player combat. Unrelated scene actors remain in their normal states.

It uses the existing private fixture builder against coordinated stable native objects; no production source changes or shared build. Two focused tests check framing and prohibit the former direct health/state/position/corpse-conversion shortcuts. Runtime evidence is recorded in the private output directory. This diagnostic does not establish arbitrary offscreen death behavior, full P2 FSM fidelity, or manual combat acceptance.

Actual private runtime PASS at output/p2-uji-legal-batch/runs/24ea66f748ab442595efb6fed8a8f542: both state1 buried attacks rejected; both normal state3 emerged targets accepted10000 stored damage from InteractAttack with pre-hit health50; both subsequently produced native corpses. No health/state/position writes were used. This confirms the tested legitimate path works and the former failure was invalid fixture setup; it does not certify all offscreen scenarios.
