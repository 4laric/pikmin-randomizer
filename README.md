# Pikmin Randomizer

Independent planning repository for a native-PC Pikmin 1 part-placement randomizer and optional later-series mechanics.

See [the implementation specification](SPEC.md) and the issue tracker for milestones, dependencies and acceptance criteria. The first milestone is a standalone, saveable solo/AP randomizer; Purple/White Pikmin, treasures and an authored cave follow base-game validation.

Status: specification and backlog. Native implementation exists in separate local research snapshots and is not published here. This repository contains no game assets or playable release.
